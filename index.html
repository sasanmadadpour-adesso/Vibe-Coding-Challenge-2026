02 / GET READY TO BUILD

Four steps.
Zero guesswork.

Your first build starts with a clean setup. Follow these steps on the coding laptop for your team.

<ready/>
01

Install the essentials

Install Git, Node.js LTS, and OpenCode. You can use PowerShell on Windows or Terminal on macOS. VS Code is optional.

Git ↗Node.js LTS ↗OpenCode docs ↗
02

Clone your private repository

Open your team's repository card above. Copy its HTTPS clone URL and use git clone. Ask the organizer for access if needed.

EXAMPLE · REPLACE WITH YOUR TEAM URLgit clone <YOUR_TEAM_REPOSITORY_URL>cd <YOUR_PROJECT_DIRECTORY>
03

Configure OpenCode

Download the safe public starter file. Save it as opencode.json in your team project root. The organizer must add the approved AI Hub provider configuration separately.

Connect & create

Launch OpenCode in your project directory. Connect to the approved provider with the credential assigned to this laptop. Use /models and send a short test prompt.

04 / THE IMPORTANT DETAILS

A few things
to know.

Need help with the setup? Ask your event organizer.

Do I need VS Code to participate? +

No. OpenCode runs in PowerShell or Terminal. An IDE is optional.

My team repository won't open. What now? +

Team repositories are private. Confirm you're signed in with an account that has access, then ask the organizer to grant the right permissions. Do not use somebody else's account or token.

Where do I enter my API key? +

The organizer provides a device-specific credential through an approved private process. Enter it only in the approved OpenCode authentication workflow, not in this website or a GitHub file.

Is the public starter configuration ready to use? +

Not by itself. The JSON download intentionally contains no company endpoint, model IDs, or credentials. The organizer must supply and validate the approved AI Hub provider settings first.
